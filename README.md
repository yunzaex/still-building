# STILL BUILDING

A personal website and digital archive for projects, notes, archive pieces, and things still in progress.

## Overview

STILL BUILDING is a personal portfolio and archive website designed to collect my projects, notes, current interests, and visual records in one place.

The site focuses on an editorial, calm, and archive-like visual language, using large typography, subtle lines, muted colors, and image-driven layouts.

## Features

- Editorial home layout with large typography and visual hero image
- Project gallery with image, metadata, role, and tag information
- Responsive layout for desktop and mobile screens
- Reusable UI components such as Navbar, Footer, Container, PageHeader, Divider, and ProjectCard
- Design tokens for typography, color
- Archive-oriented page structure for future notes, projects, and records

## Design Direction

The visual direction of this project is based on the following keywords:

- Editorial
- Archive
- Calm
- Crafted
- Minimal

The design uses a muted blue-gray background, warm brown text, thin borders, and spacious layouts to create the mood of a quiet personal archive.
